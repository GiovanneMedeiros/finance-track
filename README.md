# 💸 FinanceTrack

Um dashboard financeiro moderno, intuitivo e focado em experiência, desenvolvido para oferecer controle completo de gastos com uma interface elegante no estilo fintech.

---

## 🚀 Sobre o projeto

O **FinanceTrack** é uma aplicação web que permite ao usuário gerenciar suas finanças pessoais de forma simples, visual e eficiente.

A proposta do projeto é unir:

* 📊 Visualização clara dos dados
* ⚡ Interações rápidas e fluidas
* 🎯 Foco em experiência do usuário
* 💼 Aparência de produto real (nível mercado)

---

## ✨ Funcionalidades

* 💰 **Controle de saldo disponível**

  * Edição de saldo com persistência local
  * Atualização em tempo real

* 📄 **Importação de fatura**

  * Simulação de upload de faturas
  * Extração e exibição de transações
  * Estrutura preparada para evolução com OCR/backend

* 🧾 **Gestão de transações**

  * Listagem de gastos
  * Categorias (Transporte, Lazer, Alimentação, etc.)
  * Datas e valores organizados

* 📈 **Dashboard interativo**

  * Resumo financeiro
  * Receitas vs despesas
  * Insights rápidos

* 🎨 **Interface moderna**

  * Design dark premium (estilo fintech)
  * Microinterações e animações suaves
  * Layout responsivo

---

## 🧠 Diferenciais do projeto

Este projeto foi desenvolvido com foco em simular um produto real, indo além de um simples CRUD:

* UX refinada (inputs de moeda, feedback visual, estados)
* Estrutura pensada para escalar (componentização)
* Separação entre dados "mockados" e estrutura futura real
* Preparado para integração com backend e APIs

---

## 🛠️ Tecnologias utilizadas

* ⚛️ React (Vite)
* 🎨 Tailwind CSS
* 🎞️ Framer Motion (animações)
* 💾 LocalStorage (persistência)
* 🧩 Componentização modular

---

## 📦 Como rodar o projeto

```bash
# Clonar repositório
git clone https://github.com/GiovanneMedeiros/finance-track.git

# Entrar na pasta
cd finance-track

# Instalar dependências
npm install

# Rodar o projeto
npm run dev
```
